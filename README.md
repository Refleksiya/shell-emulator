# Эмулятор оболочки ОС (вариант 20)

## Общее описание

Графическое приложение (tkinter), которое имитирует работу командной
строки UNIX-подобной ОС. Пользователь вводит команду в нижнюю строку
и нажимает Enter, результат появляется в окне.

Выполнены все этапы: **1 — REPL**, **2 — Конфигурация**, **3 — VFS**,
**4 — Основные команды**, **5 — Дополнительные команды**.

## Функции и настройки

| Что | Описание |
|-----|----------|
| Заголовок окна | Содержит имя VFS (из `--vfs`, иначе `vfs`) |
| `--vfs ПУТЬ` | Путь к физическому расположению VFS |
| `--script ПУТЬ` | Путь к стартовому скрипту |
| Отладочный вывод | При запуске в окне печатаются все параметры |
| Стартовый скрипт | Команды по одной в строке, комментарии через `#`. В окне видны и ввод, и вывод. При ошибке скрипт останавливается и сообщает номер строки |
| Парсер | Делит строку на слова, учитывает кавычки, раскрывает переменные окружения (`$HOME`, `$USER` и т.д.) |
| `ls [путь]` | Выводит содержимое каталога VFS, папки помечены слешем |
| `cd [путь]` | Переход по VFS, поддерживает `/`, `..` и `.`; текущий каталог виден в приглашении |
| `uname [-a]` | Имя системы, с `-a` — подробные сведения |
| `echo ...` | Выводит свои аргументы |
| `uptime` | Время работы эмулятора |
| `rm [-r] путь` | Удаляет файл, с `-r` — каталог целиком (только в памяти) |
| `cp [-r] источник приёмник` | Копирует файл, с `-r` — каталог (только в памяти) |
| `exit` | Закрывает эмулятор; с аргументами — ошибка |
| VFS | Загружается из ZIP-архива целиком в память. Архив не распаковывается и не изменяется. Содержимое файлов хранится в base64 |
| Ошибки | Неизвестная команда, неверные аргументы, незакрытая кавычка, VFS не найдена, неверный формат VFS |

## Структура

```
src/shell.py   — парсер и команды
src/vfs.py     — виртуальная файловая система
src/errors.py  — класс ошибки
src/gui.py     — окно (tkinter)
src/main.py    — точка входа
tests/         — тесты (unittest)
examples/      — стартовые скрипты эмулятора
vfs_src/       — исходные папки для сборки VFS
build/         — собранные архивы VFS (в репозиторий не попадают)
scripts/       — скрипты ОС для проверки параметров (.sh и .bat)
```

## Запуск и тесты

Нужен только Python 3.8+ (tkinter входит в стандартную поставку).

```sh
./run.sh               # Linux / macOS
run.bat                # Windows
python scripts/make_vfs.py   # собрать архивы VFS в папку build
./run.sh --vfs build/deep.zip --script examples/stage3.txt
python -m unittest discover tests -v   # тесты
```

## Примеры использования

```
$ ls -l $HOME
ls, аргументы: ['-l', '/home/user']
$ cd "my folder"
cd, аргументы: ['my folder']
$ cd a b
Ошибка: cd: слишком много аргументов
$ hello
Ошибка: hello: команда не найдена
$ ls "abc
Ошибка: ошибка разбора: незакрытая кавычка
$ exit
```

Стартовый скрипт `examples/error.txt`:

```
$ ls -a
ls, аргументы: ['-a']
$ hello
Ошибка: hello: команда не найдена
Скрипт остановлен: ошибка в строке 3
```

Загрузка VFS:

```
Параметры запуска:
  VFS: build/deep.zip
  Стартовый скрипт: examples/stage3.txt

VFS загружена: build/deep.zip
```

Ошибка загрузки VFS:

```
Ошибка: неверный формат VFS, нужен ZIP: README.md
```

Команды этапа 4:

```
/$ ls
docs/  root.txt
/$ cd docs/reports/2026
/docs/reports/2026$ ls
year.txt
/docs/reports/2026$ uname -a
EmulatorOS deep.zip 1.0 x86_64
/docs/reports/2026$ echo привет
привет
/docs/reports/2026$ cd nope
Ошибка: нет такого файла или каталога: nope
```

Команды этапа 5 (исходный архив при этом не меняется):

```
/$ cp root.txt copy.txt
/$ cp -r docs backup
/$ ls
backup/  copy.txt  docs/  root.txt
/$ rm copy.txt
/$ rm -r backup
/$ rm docs
Ошибка: rm: это каталог, нужен -r: docs
```
