# Эмулятор оболочки ОС (вариант 20)

## Общее описание

Графическое приложение (tkinter), которое имитирует работу командной
строки UNIX-подобной ОС. Пользователь вводит команду в нижнюю строку
и нажимает Enter, результат появляется в окне.

Выполнены этапы: **1 — REPL**, **2 — Конфигурация**.
Команды `ls` и `cd` пока заглушки.

## Функции и настройки

| Что | Описание |
|-----|----------|
| Заголовок окна | Содержит имя VFS (из `--vfs`, иначе `vfs`) |
| `--vfs ПУТЬ` | Путь к физическому расположению VFS |
| `--script ПУТЬ` | Путь к стартовому скрипту |
| Отладочный вывод | При запуске в окне печатаются все параметры |
| Стартовый скрипт | Команды по одной в строке, комментарии через `#`. В окне видны и ввод, и вывод. При ошибке скрипт останавливается и сообщает номер строки |
| Парсер | Делит строку на слова, учитывает кавычки, раскрывает переменные окружения (`$HOME`, `$USER` и т.д.) |
| `ls [аргументы]` | Заглушка: выводит имя и аргументы |
| `cd [путь]` | Заглушка: выводит имя и аргументы; больше одного аргумента — ошибка |
| `exit` | Закрывает эмулятор; с аргументами — ошибка |
| Ошибки | Неизвестная команда, неверные аргументы, незакрытая кавычка |

## Структура

```
src/shell.py   — парсер и команды
src/gui.py     — окно (tkinter)
src/main.py    — точка входа
tests/         — тесты (unittest)
examples/      — стартовые скрипты эмулятора
scripts/       — скрипты ОС для проверки параметров (.sh и .bat)
```

## Запуск и тесты

Нужен только Python 3.8+ (tkinter входит в стандартную поставку).

```sh
./run.sh               # Linux / macOS
run.bat                # Windows
./run.sh --vfs examples/my_vfs.zip --script examples/ok.txt
python -m unittest discover tests -v   # тесты
```

## Примеры использования

```
$ ls -l $HOME
ls, аргументы: ['-l', '/home/user']
$ cd "my folder"
cd, аргументы: ['my folder']
$ cd a b
Ошибка: cd: слишком много аргументов
$ hello
Ошибка: hello: команда не найдена
$ ls "abc
Ошибка: ошибка разбора: незакрытая кавычка
$ exit
```

Стартовый скрипт `examples/error.txt`:

```
$ ls -a
ls, аргументы: ['-a']
$ hello
Ошибка: hello: команда не найдена
Скрипт остановлен: ошибка в строке 3
```
